# Reflection

Laboratory 01 gave me an introduction to the basic environment and responsibilities of a cloud infrastructure engineer. I learned how to access a Linux environment using KillerCoda and how to work with the terminal using different Linux commands.

One of the important activities was creating a new Linux user and learning how to switch between accounts. I also learned how to check system information such as the Linux distribution, kernel version, CPU, memory, and available disk space.

I also learned the importance of organizing technical files and documenting my work using Markdown. Creating a GitHub repository helped me understand how cloud engineers can use version control to maintain and present their technical work.

Overall, this laboratory provided me with a foundation in Linux, GitHub, documentation, and cloud computing. I will use these skills in the succeeding laboratory activities.

# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic responsibilities of a cloud infrastructure engineer. The mission focuses on accessing a Linux cloud environment, managing users, exploring system information, organizing files, documenting technical activities, and creating a GitHub portfolio.

## Objectives

* Access a cloud-based Linux environment using KillerCoda.
* Navigate and manage the Linux file system.
* Create and manage a Linux user account.
* Gather basic system information.
* Organize files and directories.
* Create Markdown documentation.
* Create and maintain a GitHub repository.
* Document technical work professionally.

## Activities Performed

1. Accessed an Ubuntu Linux environment through KillerCoda.
2. Created the required Linux user account.
3. Logged in to the newly created user account.
4. Checked the username, working directory, and hostname.
5. Gathered Linux distribution, kernel, CPU, memory, and disk information.
6. Created the required directory structure.
7. Created Markdown documentation.
8. Created the CCM101 Cloud Computing Portfolio repository on GitHub.
9. Organized Laboratory 01 files and screenshots.
10. Committed and pushed the completed work to GitHub.

## Skills Learned

Through this laboratory activity, I learned how to access and work inside a Linux cloud environment. I also learned how to create users, navigate directories, gather system information, organize files, write Markdown documentation, and use GitHub as a version-controlled portfolio.

These skills provide a foundation for future cloud infrastructure, Linux administration, and cloud computing activities.
